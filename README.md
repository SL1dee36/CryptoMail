# CryptoMail

Защищенная локальная почтовая система с веб-интерфейсом и консольной утилитой. Написана на Python (FastAPI + SQLAlchemy) и сочетает российские криптостандарты (ГОСТ) со сверхдлинными ключами RSA.

## Что умеет проект

* **Гибридное шифрование писем**:
  * **RSA (включая RSA-32768, 32K бит)** — чистая реализация на Python (без библиотеки `cryptography`): набивка RSA-OAEP (SHA-256 / MGF1), экспорт/импорт PEM (PKCS#1, PKCS#8, SPKI), CRT-ускорение, генерация на всех ядрах CPU или мгновенная сборка из предвычисленных $p$ и $q$.
  * **ГОСТ Р 34.12-2015 «Кузнечик»** (128 бит блок, 256 бит ключ) в режимах CBC и CTR.
  * **ГОСТ Р 34.11-2012 «Стрибог»** (512 и 256 бит) + потоковый режим с контролем целостности через HMAC.
* **ЭЦП и сертификаты**: национальный стандарт электронной цифровой подписи **ГОСТ Р 34.10-2012** (512 и 256 бит, RFC 7091 / RFC 7836) с хэш-функцией «Стрибог-512» / «Стрибог-256». Полная реализация на чистом Python без зависимости от сторонней библиотеки cryptography. При чтении письма подпись автоматически проверяется.
* **Трехфакторная аутентификация (3FA)**:
  1. Пароль (хешируется через PBKDF2-Стрибог-512 с солью).
  2. Одноразовый код из письма (приходит на встроенный SMTP-сервер).
  3. Код из приложения-аутентификатора (TOTP) или разовый код восстановления (Recovery Code).
* **Шифрование базы на диске (Encryption at Rest)**: все приватные ключи, тела сообщений и резервные коды шифруются в SQLite шифром «Кузнечик». Если скопировать файл базы `cryptomail.db`, прочитать переписку без ключа не получится.
* **Экспорт переписки**: скачивание входящих и исходящих писем в JSON и PDF (с аккуратной версткой таблиц и русским шрифтом).

## Быстрый старт

### 1. Установка зависимостей

Рекомендуется создать виртуальное окружение:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Запуск приложения

```powershell
python -m main
```

После запуска сервер поднимет:
* **Веб-интерфейс**: [http://127.0.0.1:8000](http://127.0.0.1:8000)
* **Встроенный ящик MailTrap (для кодов 3FA)**: [http://127.0.0.1:8000/mailtrap](http://127.0.0.1:8000/mailtrap)
* **Локальный SMTP-сервер**: `127.0.0.1:1025` (принимает письма от приложения в фоне)

---

## Готовые учетные записи для входа

При первом запуске база автоматически заполняется тестовыми пользователями:

| Логин   | Пароль              | Роль                | Что может делать                                                                       |
|---------|---------------------|---------------------|----------------------------------------------------------------------------------------|
| `admin` | `AdminPassword123!` | **Админ**           | Панель управления, сброс паролей пользователей, аудит и экспорт всей переписки системы |
| `alice` | `AlicePassword123!` | **Пользователь**    | Отправка и чтение шифрованных писем, подпись ЭЦП, личный экспорт                       |
| `bob`   | `BobPassword123!`   | **Пользователь**    | Прием писем, проверка ЭЦП отправителя                                                  |
| `guest` | `GuestPassword123!` | **Гость**           | Только чтение (отправка писем заблокирована)                                           |

### Как войти:
1. Вводим логин и пароль.
2. На шаге 2 открываем в соседней вкладке [http://127.0.0.1:8000/mailtrap](http://127.0.0.1:8000/mailtrap), берем свежий 6-значный код из письма и вставляем в форму.
3. На шаге 3 вводим TOTP-код либо используем один из резервных кодов (для нового аккаунта они показываются при регистрации через `/register`).

## Консольная утилита (`cli.py`)

Все криптографические модули можно запускать напрямую из консоли без веб-интерфейса.

### RSA и RSA-32K
```powershell
# Заранее сгенерировать простые p и q для 32K ключа (сохраняются в data/rsa_pregen/)
python cli.py rsa-pregen

# Мгновенно собрать ключ RSA-32768 из предвычисленных p и q
python cli.py rsa --generate --bits 32768 --pregen --out-priv priv32k.pem --out-pub pub32k.pem

# Честная генерация RSA-4096 на всех ядрах процессора (со счетчиком в реальном времени)
python cli.py rsa --generate --bits 4096 --out-priv priv.pem --out-pub pub.pem

# Зашифровать и расшифровать файл или строку
python cli.py rsa --encrypt --pub pub.pem --data "Привет, секрет!" --out-file bundle.json
python cli.py rsa --decrypt --priv priv.pem --in-file bundle.json

# Быстрый тест 4K или 32K ключа (прогоняет сквозной цикл)
python cli.py demo-rsa-4k
python cli.py demo-rsa-32k --pregen
```

### ГОСТ «Кузнечик»
```powershell
# Проверка эталонного примера из RFC 7801
python cli.py kuznyechik --demo

# Зашифровать строку в режиме CBC
python cli.py kuznyechik --encrypt --key 8899aabbccddeeff0011223344556677fedcba98765432100123456789abcdef --data "Тестовые данные" --mode cbc
```

### ГОСТ «Стрибог»
```powershell
# Проверка тестового вектора из RFC 6986
python cli.py streebog --demo

# Хеширование строки (512 бит)
python cli.py streebog --data "Секретный текст" --bits 512

# Вычисление HMAC
python cli.py streebog --data "Документ" --key "секретный_ключ" --hmac
```

### ЭЦП (ГОСТ Р 34.10-2012)
```powershell
# Быстрая сквозная демонстрация ГОСТ Р 34.10-2012 и проверка эталона RFC 7091
python cli.py demo-ecp

# Выпустить себе сертификат и пару ключей (512 бит по умолчанию)
python cli.py ecp --generate-cert --name "Иван Иванов" --out-cert cert.json --out-priv ecp_priv.pem --out-pub ecp_pub.pem

# Подписать данные
python cli.py ecp --sign --priv ecp_priv.pem --data "Приказ №1"

# Проверить подпись
python cli.py ecp --verify --pub ecp_pub.pem --sig "<base64_подпись>" --data "Приказ №1"
```

## Тестирование

Запуск полного набора модульных тестов:

```powershell
python -m unittest discover -s tests -v
```

Тесты проверяют соответствие ГОСТам RFC 7801 («Кузнечик»), RFC 6986 («Стрибог»), RFC 7091 (ЭЦП ГОСТ Р 34.10-2012), работу 3FA, локальный SMTP, шифрование базы и связку RSA-32K.
